## Dicas de publicação
- **Texto alternativo:** em cada post, use “Configurações avançadas → Escrever texto
  alternativo” com uma frase descrevendo a imagem (ajuda a acessibilidade e o alcance).
- **Stories:** compartilhe cada post nos stories com uma enquete
  (ex.: no post 2, “Sua internet já caiu essa semana? Sim / Não”).
- **Destaque:** crie um destaque “Monitoramento” no perfil com esses stories.
- **Telas da plataforma:** são telas reais da NexoPulse com dados de demonstração;
  os nomes de sites (Fazenda Boa Vista, Filial Litoral…) são fictícios.
