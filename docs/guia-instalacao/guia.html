1 Antes de começar

Como o sensor funciona

O NexoPulse Edge é um serviço que roda na rede do cliente, mede a conexão e manda tudo para a Central. Ele sobe sozinho quando a máquina liga, volta sozinho se cair e se atualiza sozinho quando sai uma versão nova.

Máquina Linux

  • Debian / Ubuntu / Linux Mint, Arch / CachyOS, Fedora ou openSUSE
  • Acesso à internet
  • Um usuário comum com permissão de sudo

Máquina Windows

  • Windows 11 versão 22H2 ou mais nova
  • Acesso à internet
  • Conta com permissão de Administrador

O que o instalador faz sozinho

  • Baixa o sensor direto da Central — não é preciso copiar nada para a máquina antes.
  • Instala o que falta (Python e ferramentas de rede) e cria o serviço nexopulse-edge.
  • Deixa o serviço ligado no boot, com reinício automático e proteção de atualização.
  • Registra o sensor na Central no primeiro contato e avisa o grupo NexoPulse · Alertas no Telegram.

Duas escolhas antes de rodar o comando

OpçãoPara que serveComo usar
Nome do sensorNome que aparece na Central. Se não informar, usa o nome da máquina. Pode ser trocado depois na Central.Linux: NOC_SENSOR_NOME="…"
Windows: -NomeSensor "…"
Ações de root
(opcional)		Libera Atualizar sistema operacional e Reiniciar a máquina pela Central. Sem ela, todo o resto funciona normalmente.Linux: NEXOPULSE_ROOT=1
Windows: -Root
Libere o root só onde fizer sentido

Com as ações de root, a Central passa a poder atualizar e reiniciar a máquina. Por isso a instalação padrão vem sem root. Mesmo liberadas, cada uso exige ligar as ações remotas do sensor e confirmar com a senha do Administrador Master. Dá para liberar ou desfazer depois (veja a página 5).

2 Linux

Instalação em máquina Linux

Tudo pelo terminal, com um único comando. Leva de 2 a 5 minutos, dependendo da internet.

  1. Abra um terminal como usuário normal

    Não use root nem sudo su: o instalador pede o sudo sozinho quando precisa.

  2. Rode o comando de instalação

    Troque Loja Centro pelo nome do local:

    Terminalcurl -fsSL https://nexopulse.up.railway.app/instalar.sh | NOC_SENSOR_NOME="Loja Centro" bash

    Pode colar as duas linhas como estão. Para liberar também as ações de root, acrescente NEXOPULSE_ROOT=1:

    Com rootcurl -fsSL https://nexopulse.up.railway.app/instalar.sh | NOC_SENSOR_NOME="Loja Centro" NEXOPULSE_ROOT=1 bash
  3. Digite a senha do sudo quando pedir

    É a senha do seu usuário nessa máquina. Ela não aparece enquanto você digita — é normal.

  4. Espere a mensagem de conclusão
    ✅ NexoPulse Edge instalado, iniciado e configurado para subir com a máquina.

    Logo abaixo ele mostra se as ações de root ficaram liberadas e onde está a configuração.

  5. Confira na Central

    Em até 1 minuto o sensor aparece na lista de sensores e o grupo NexoPulse · Alertas recebe “SENSOR VINCULADO”.

Conferir pela máquina (opcional)

Terminalsudo systemctl status nexopulse-edge --no-pager

Deve mostrar active (running) e enabled.

3 Windows

Instalação em máquina Windows

No Windows o sensor roda dentro do WSL (um Linux integrado ao Windows), enxergando a rede real da máquina. O instalador cuida de tudo.

  1. Abra o PowerShell como Administrador

    Clique com o botão direito no menu Iniciar → Terminal (Admin).

  2. Rode o comando de instalação

    Troque Loja Centro pelo nome do local:

    PowerShellirm https://nexopulse.up.railway.app/instalar-windows.ps1 ` -OutFile $env:TEMP\nexopulse.ps1 powershell -ExecutionPolicy Bypass -File $env:TEMP\nexopulse.ps1 ` -NomeSensor "Loja Centro"

    Para liberar também as ações de root, acrescente -Root depois de "Loja Centro". Pode colar as linhas como estão: o PowerShell junta as que terminam em crase.

  3. Só na primeira vez: crie o usuário do Linux

    Se o Ubuntu ainda não existia, o instalador o instala e para. Abra o Ubuntu pelo menu Iniciar, crie um usuário e uma senha, feche a janela e rode o passo 2 de novo. Se o Windows pedir, reinicie antes.

  4. Digite a senha do Linux quando pedir

    Ele instala o sensor dentro do Ubuntu e cria a tarefa “NexoPulse Edge (WSL)”, que liga o sensor sempre que o Windows inicia.

  5. Confira na Central

    O sensor aparece em até 1 minuto, e o grupo NexoPulse · Alertas recebe “SENSOR VINCULADO”.

Conferir pelo Windows (opcional)

PowerShellwsl -d Ubuntu -- systemctl status nexopulse-edge --no-pager
Bom saber

O computador precisa ficar ligado para o sensor medir. No WSL não há leitura de temperatura da CPU; o resto das medições é igual ao Linux.

4 Depois de instalar

Ajustes na Central

Com o sensor no ar, o resto é feito pela plataforma.

Nome

Troque quando quiser na tela do sensor; a Central nunca o sobrescreve.

Cliente

Vincule na tela Sensores: com Chat ID, o grupo do cliente recebe os alertas.

Atualização automática

Sempre que o código do sensor muda na Central, ele se atualiza sozinho de madrugada (04h), cada sensor num minuto diferente. Antes de trocar, guarda a versão atual: se a nova não conseguir falar com a Central, ele volta sozinho para a anterior e o Telegram avisa. Dá para desligar por sensor no card Ações remotas → Atualização automática.

Ações remotas

AçãoRoot?Observação
Coletar diagnósticoNãoSistema, disco, memória, rede e serviço
Atualizar agente NexoPulse / Reiniciar serviço do agenteNãoMesma atualização da madrugada, na hora
Atualizar sistema operacionalSimAtualiza os pacotes do Linux
Reiniciar a máquinaSimReinicia em 10 segundos

Ligue o interruptor no card Ações remotas da tela do sensor (só Administrador Master). Cada ação pede a sua senha, fica registrada e avisa o grupo NexoPulse.

Liberar ou desfazer o root depois

É feito na máquina (no local, por SSH ou área de trabalho remota): de propósito, a Central não libera root sozinha. No Windows, dentro do Ubuntu (WSL).

Linux / WSL# liberar bash ~/nexopulse-edge/linux/liberar-root.sh # desfazer bash ~/nexopulse-edge/linux/liberar-root.sh --desfazer

5 Se algo der errado

Solução de problemas

Os casos mais comuns e o que fazer em cada um.

SintomaO que fazer
Sensor não aparece na CentralVeja o erro no log:
journalctl -u nexopulse-edge -n 50 --no-pager
Confira também se a máquina tem internet.
“401 Sensor não autenticado” no logA chave do sensor mudou. Na Central, Sensores → excluir o sensor e reinicie o serviço: ele se vincula de novo.
Windows: não volta depois de reiniciar o PCConfira se a tarefa “NexoPulse Edge (WSL)” existe no Agendador de Tarefas. Se não, rode o instalador de novo.
“Atualizar sistema operacional” ou “Reiniciar a máquina” falhamAs ações de root não foram liberadas nessa máquina. Na máquina, rode:
bash ~/nexopulse-edge/linux/liberar-root.sh
Atualização desfeita (aviso no Telegram)A versão nova não conseguiu falar com a Central e o sensor voltou para a anterior sozinho. Nada a fazer na máquina: ele tenta de novo quando sair a próxima versão.
Precisa reinstalarRode o mesmo comando de instalação. Nome, identidade e chave do sensor são preservados.
